A2 候选质量诊断补充（2026-09-13）

为了进一步看清“正样本变多”是否带来了相应的监督增量，补了一组小规模诊断：固定 fixed seed 20260826 的第120轮 last.pt 和16张预选训练图像，使用相同预测，只切换 pure TAL、fixed、adaptive 分配规则，没有重新训练。

在这组输入的1321个 small GT 中，adaptive 相对 fixed 的平均正样本数增加57.88%，平均 target score 之和增加8.65%。零正样本比例从9.0083%降至6.8887%，但零权重 GT 比例从9.0083%变为9.1597%。这个区别提醒我，统计 mask 数量之外，还需要看新增位置实际承担了多少监督。
